# Introduction

Sway is a .NET UI toolkit with a [Flutter](https://flutter.dev)-style widget system. You describe your interface as a
tree of immutable widgets in C#; Sway diffs it, lays it out with box constraints, and paints it with
[SkiaSharp](https://github.com/mono/SkiaSharp) into a native OpenGL window — no browser, no WebView, no XAML.

```csharp
// using Sway.Extras.Material3;
App.Run(new MaterialApp(home: new CounterPage()), "My App", 800, 600);
```

```csharp
class CounterPage : StatefulWidget
{
    public override State CreateState() => new CounterPageState();
}

class CounterPageState : State<CounterPage>
{
    int _count;

    public override Widget Build(BuildContext context) => new Scaffold(
        appBar: new AppBar(title: new Text("Counter")),
        body: new Center(new Text($"Count: {_count}", style: Theme.Of(context).TextTheme.DisplaySmall)),
        floatingActionButton: new FloatingActionButton(new Icon(Icons.Add), () => SetState(() => _count++)));
}
```

## The model

Sway follows Flutter's three trees:

- **Widgets** are cheap, immutable descriptions (`Container`, `Row`, `Text`, `TextField`...). `Build` returns them.
- **Elements** are the long-lived instances that Sway diffs against the new widgets. They hold `State`, resolve
  `Theme.Of(context)` and `Directionality.Of(context)`, and decide what to rebuild.
- **Render objects** do layout (constraints go down, sizes go up), painting and hit testing.

## What is included

- Layout: `Row`, `Column`, `Flex`, `Stack`, `Wrap`, a CSS-grid-style `Grid`, `Padding`, `Align`, `SizedBox`,
  `ConstrainedBox`, `AspectRatio`, `IntrinsicWidth` and more.
- Design systems as optional packages. `Sway.Extras.Material3`: colour scheme (baseline or seeded), type scale, elevation,
  light and dark modes, buttons, text fields with floating labels, selection controls, dropdowns, cards, lists, chips, navigation,
  dialogs and snack bars.
- Text with HarfBuzz shaping, wrapping, rich spans and right-to-left support (`Directionality`, bidi runs, mirrored
  layouts).
- Input: tap and drag gestures with a gesture arena, hover and cursors, focus and Tab traversal, a full text editor
  (selection, clipboard, undo), scrolling with fling and lazy lists.
- Animation: `AnimationController`, curves, tweens, transitions and implicit widgets such as `AnimatedContainer`.
- Effects: shadows, gradients, clips, transforms, blur and colour filters.
- Platform hosts: a desktop window via [Silk.NET](https://github.com/dotnet/Silk.NET) (`Sway.Platform.Desktop`),
  Android (`Sway.Platform.Android`), the browser (`Sway.Platform.Web`) and a headless mode that renders straight to
  PNG for screenshot-based checks (`Sway.Platform.Headless`).
- `Sway.Extras.Ibm`: IBM Carbon, with its own theme tokens, IBM Plex type, form controls and a data table.
- Optional video and audio playback through LibVLC (`Sway.Media`, with Material 3 players in `Sway.Extras.Material3.Media`).

## What is not (yet)

Sway is young. Known gaps are tracked in [Known limits](./known-limits): no accessibility tree, no `Navigator`, a
subset of Material 3 components, Windows-first font handling, and no automated test suite yet.
